# Download folder — retired

There is **no package file in this folder anymore**. The installer
`Lianwang-Setup-1.1.1.exe` (~140 MB) is too big for GitHub's 25 MB per-file
repo limit, so it is hosted as a **GitHub Release asset** instead:

https://github.com/ykminmin8654/LianWang-Innovation-Earth-Projects/releases/tag/install

The download buttons on the site link straight to that Release asset (same
tab), and `js/lianwang.js` verifies it through the GitHub API and shows its
real size. The Setup .exe is the **only** download option; the earlier
portable .zip release was retired.

See `PUBLISHING.md` next to this file for the full ship workflow.
