# Download folder — retired

There is **no package file in this folder anymore**. The portable
`Lianwang-v1.1.0-portable.zip` (the app's only download option) is too big for
GitHub's 25 MB per-file repo limit, so it is hosted as a **GitHub Release
asset** instead:

https://github.com/ykminmin8654/LianWang-Innovation-Earth-Projects/releases

The download buttons on the site link straight to that Release (same tab), and
`js/lianwang.js` auto-detects the latest release's zip through the GitHub API.
