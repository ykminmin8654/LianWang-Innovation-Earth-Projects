How setup works
Getting started

Extract the zip, then open the app

Liánwǎng ships as a single portable .zip — no installer. From the planned user guide: choose a preset, wait for the first-run configuration, and pin what you use most to the sidebar.

  1. 01

    Download & extract

    Grab Lianwang-v1.1.0-Web-Installer.zip from the GitHub Release, right-click it → Extract All… into a folder you keep (e.g. D:\Apps\Liánwǎng), then launch Lianwang.exe.

  2. 02

    Pick a preset

    Essential · Focus · Creator · Image & Media · Utilities · All Tools — or Custom to select each tool yourself.

  3. 03

    Wait for first run

    The welcome screen configures selected tools and storage. Don't close the window — later launches skip straight to Home.

  4. 04

    Make it yours

    Settings → Appearance for themes, Settings → Tools to add or remove tools, drag items in the sidebar to pin your daily set.

Development note on presets

Preset names and contents shown here match the v1.1.0 user guide and may change before release. The Drive tool remains hidden — it isn't part of normal installation yet, and its status is tracked on the roadmap below.

Questions

Frequently asked

Is Liánwǎng finished?

No — it is still in active development. The v1.1.0 user guide describes the planned experience, and parts of it (Drive, some export flows, app signing) are not final yet. Everything you read here is marked as pre-release.

Why does the download button go to GitHub instead of a file on this site?

The portable Lianwang-v1.1.0-Web-Installer.zip is bigger than GitHub's 25 MB per-file limit for repositories, so it can't live inside the site's files. It is attached to a GitHub Release of this repo instead, and the download buttons link straight to that Release asset (same tab — no pop-ups). Once the Release is published, the page also shows the zip's real size automatically.

Is there a Setup.exe installer?

Not right now — the portable .zip is the only download option. Extract it with right-click → Extract All…, keep the folder somewhere permanent, and run Lianwang.exe. A classic installer may return after launch; until then nothing else is offered, so you can't grab the wrong file by accident.

My build is bigger than 25 MB — GitHub won't let me upload it to the repo. What now?

That's expected: GitHub blocks repo files over 25 MB via the web editor (and hard-blocks anything over 100 MB). The fix is GitHub Releases, which accept assets up to 2 GB — this site already uses that path for the zip:

  1. Open your repo → Releases → Draft a new release.
  2. Create a tag (any name — ours is ZIP), tick pre-release while the app is in development, drag your zip (ours: Lianwang-v1.1.0-Web-Installer.zip) into the "attach binaries" area, then publish.
  3. Nothing else to configure: the site finds the latest Release's zip through the GitHub API and links the buttons straight at the file. If you rename the zip, update releaseAssetName in js/lianwang.js (optional).

Until a Release exists, the badge reads "Release not published yet" but the buttons still take users to the Releases page rather than dead-ending. No Git LFS needed — LFS has quota limits and still bloats the repo.

Does it need an account or internet?

Neither. Tasks, calendar, notes, passwords, video projects and edits are stored locally on your PC. Internet access is optional and used only if you enable Drive-style syncing later.

Which Windows versions are supported?

Windows 10 and 11 on x64 machines. Extract the zip, launch the app, choose a preset (or Custom), and let the first-run configuration finish without closing the window.

Can I change which tools are installed?

Yes — Settings → Tools adds or removes tools; the same preset choice also appears on first run after extracting a new build. The sidebar shows everything currently enabled.

Can I try the unreleased tools?

When the beta build is published, early-access builds will be offered to testers. Email InnovationEarthProjects@gmail.com and tell us which tool you want to break first.
